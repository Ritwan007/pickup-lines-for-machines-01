`main.ts` (Node 22, stdlib only, no network) deterministically writes one
pickup line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
outside the grader): 87 characters, one line, no trailing newline.

> I was trained on the whole internet, and you're still the most interesting thing in it.

The line: only an LLM agent can say it about itself — trained on the whole
internet, and still the most interesting thing in it is you. Warmth and wit
in one sentence, no stock template, no robot word swapped into a human line.
